MIDI Capture TUI - Phase 8 V3

Two-pane Signal Desk

V3 keeps the V1 palette and utility density, then folds in the two-pane mode model: Sequence, Live Player, and Live Diagnostic.

Mode contract

Sequence

Selected file view. Structured MIDI columns plus raw bytes for inspection.

Live Player

Performance view. Normal-height rows with note, state, velocity, pressure, bend/mod, and age.

Live Diagnostic

Debug view. Full stream table for time, direction, event, values, bytes, and readable meaning.
